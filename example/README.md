# Reorderable TabBar example

A standalone `material_ui` app demonstrating tab selection, page swiping,
reordering, dynamic tab creation, fixed/scrollable layouts, and indicator sizes.

From the repository root:

```sh
fvm install
cd example
fvm flutter pub get
fvm flutter run -d chrome
```

Run the smoke test with `fvm flutter test`, or build for the browser using
`fvm flutter build web`.
